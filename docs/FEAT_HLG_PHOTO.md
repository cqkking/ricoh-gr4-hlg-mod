# Feature Design & Engineering Spec: HLG HDR Still Photography (`feat/hlg-photo`)

## 1. Architectural Context on Ricoh GR IV (v1.11)

Empirical static analysis of the Ricoh GR IV v1.11 firmware (`fwdc248b.bin`) confirms two key architectural facts that shape our staged implementation:

1. **RTOS ISP Image Control (`Look`) Pipeline (`05_RTOS.bin` @ `0x53000000`)**:
   - The 17-entry Image Control pointer table at `vaddr = 0x53dbf360` (`payload = 0x00dd7070`) includes hidden/reserved slots (`#10` `0x53dbe4ba`, `#11` `0x53dbe4be`) and a visibility gate at `vaddr = 0x533cc6e0` (`payload = 0x003e43f0`, instruction `0x533cc6e4: 0a000009 beq #0x533cc710`).
   - Meanwhile, the high-level Chips&Media WAVE H.265 wrapper (`H265_Wave_Initialize`) in `05_RTOS.bin` was stripped by linker `--gc-sections`, meaning native RTOS hardware `.HIF` (`heic`) encoding is not available out-of-the-box without either reconstructing the WAVE VDI calls or encoding on the Linux side.
2. **Staged Two-Phase Strategy**:
   - **Phase 1 (Zero-Overhead Hardware ISP Path — Ready Now)**: Repurpose a hidden Image Control (`Look`) slot in `05_RTOS.bin` with a **Linear Rec.709 $\rightarrow$ Rec.2020 3×3 Color Correction Matrix (CCM)** and a **1D ARIB STD-B67 (HLG) OETF Tone Curve LUT**, paired with an **ICC v4.4 `cicp` (`[9, 18, 0, 1]`) profile** injected into the `.JPG` `APP2` marker segment. Modern HDR displays (iOS/macOS EDR, Android Ultra HDR / CICP, Chrome/Edge) natively recognize CICP `[9, 18, 0]` inside JPEG/WebP/AVIF and activate full HLG HDR brightness scaling with zero shutter lag.
   - **Phase 2 (10-bit `.HIF` via Linux `libshmem_manager.so` + `libx265`)**: Hook the dual-OS shared memory buffer in `/usr/lib/libshmem_manager.so` (`shmem_get_address` / `shmem_NoticeCaptureStillInfo`) inside `INITFS` (`07_INITFS.bin`) to read the 14-bit raw/linear image buffer from DDR RAM and encode a 10-bit `Main10` HEVC still frame wrapped in an ISO Base Media `.HIF` (`mif1`/`heic`) container with `colr(nclx: 9, 18, 9)` and `ipma` boxes.

## 2. Phase 1 Implementation Details

### 2.1 Rec.709 $\rightarrow$ Rec.2020 3×3 Color Matrix (`CCM`)

Generated by [`src/hlg_photo/generate_hlg_lut_and_ccm.py`](../src/hlg_photo/generate_hlg_lut_and_ccm.py) and saved to [`assets/isp_tables/`](../assets/isp_tables/):

$$
M_{\text{709}\rightarrow\text{2020}} = \begin{bmatrix}
0.6274039 & 0.3292830 & 0.0433131 \\
0.0690973 & 0.9195404 & 0.0113623 \\
0.0163914 & 0.0880133 & 0.8955953
\end{bmatrix}
$$

- **Signed S3.8 Fixed-Point (`1.0 = 256`, row-sum preserved)**:
  `[[161, 84, 11], [18, 235, 3], [4, 23, 229]]`
- **Signed S3.10 Fixed-Point (`1.0 = 1024`, row-sum preserved)**:
  `[[642, 337, 45], [71, 941, 12], [17, 90, 917]]`

### 2.2 ARIB STD-B67 (HLG) 1D OETF Tone Curve LUT

$$
E' = \begin{cases}
\sqrt{3E} & 0 \le E \le \frac{1}{12} \\
a \ln(12E - b) + c & \frac{1}{12} < E \le 1
\end{cases}
\quad (a = 0.17883277,\; b = 0.28466892,\; c = 0.55991073)
$$

Binary 10-bit (`1024 × uint16`) and 12-bit (`4096 × uint16`) LUTs are output to:
- [`assets/isp_tables/arib_std_b67_hlg_1024x10bit.bin`](../assets/isp_tables/arib_std_b67_hlg_1024x10bit.bin)
- [`assets/isp_tables/arib_std_b67_hlg_4096x12bit.bin`](../assets/isp_tables/arib_std_b67_hlg_4096x12bit.bin)

### 2.3 ICC v4.4 `cicp` (`[9, 18, 0, 1]`) Profile Builder & JPEG Injector

Generated by [`src/hlg_photo/build_bt2100_hlg_icc.py`](../src/hlg_photo/build_bt2100_hlg_icc.py) and saved to [`assets/icc/bt2100_hlg_cicp.icc`](../assets/icc/bt2100_hlg_cicp.icc).

## 3. Phase 2 Linux `shmem` + 10-bit `.HIF` Pipeline Blueprint

In `INITFS` (`07_INITFS.bin`), `/usr/lib/libshmem_manager.so` exports:
- `shmem_initialize` (`0x00001610`), `shmem_get_address` (`0x00001780`), `shmem_get_size` (`0x000017e4`)
- `shmem_NoticeCaptureStillInfo` (`0x000018fc`), `shmem_RequestCaptureStillInfo` (`0x000018a8`)

By placing an `LD_PRELOAD` hook library (`libhlg_hif_hook.so`) on `/usr/bin/camctld`, when `shmem_NoticeCaptureStillInfo` fires and the custom HLG Look slot is active, a low-priority (`nice -n 19`) worker thread maps the shared memory physical region via `/dev/mem` (`libcmfwk.so` `cmfwk_mmap_open`), applies the 14-bit-to-10-bit BT.2020 + ARIB STD-B67 NEON LUT, and writes a `.HIF` file alongside the `.JPG`/`.DNG` on `/mnt/sd`.
